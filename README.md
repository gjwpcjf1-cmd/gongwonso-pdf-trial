# 공원소 PDF 무료 브라우저 시험 (G4.1)

이 저장소는 관리자 기술 실증용 **공개 정적 웹 코드만** 보관합니다. 수학싸부 PDF 원본·정답·해설·기존 2,047문항 색인·학생정보는 절대로 커밋하지 않습니다.

번호/ID 매칭 후보를 확인하는 용도이며, 교사 최종 승인, 실제 교재 등록, 학생 공개, 누적 색인 대조는 하지 않습니다. PDF 파일은 사용자의 브라우저 메모리에서만 분석되도록 설계했습니다.

정적 사이트는 GitHub Pages의 GitHub Actions 방식으로 배포합니다. 배포 후에도 실제 안드로이드 PDF 처리 시험은 별도로 확인해야 합니다.
